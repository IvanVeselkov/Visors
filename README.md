# Visors — цифровой ночной визор для страйкбола

Проект носимого устройства ночного видения (NV) на базе ESP32, камеры OV7670
и SPI-экрана 1.44" 128×128. Устройство крепится на шлем/маску и выводит
изображение перед глазом через увеличительную линзу.

Статус: **этап M2 — есть полная схема подключения и прошивка живого видео**.
Подтверждено: OV7670 — 18-пиновый модуль **без FIFO**; Arduino Nano из
видеотракта исключён; экран — 8-пиновый SPI без MISO, драйвер подбирается
опытным путём (см. `firmware/`).

## Коротко о решении

* **ESP32 — единственный вычислитель.** Arduino Nano для видео не годится:
  2 КБ ОЗУ против 32 КБ на один кадр 128×128 RGB565, и нет периферии захвата
  параллельного видеопотока.
* **OV7670 выдаёт «сырой» параллельный поток** (D0–D7, PCLK, VSYNC, HREF).
  На ESP32 он принимается через I2S в parallel-режиме (так работает esp32-camera).
* **Ночной режим — активный ИК-подсвет.** OV7670 без подсветки в темноте почти
  слепой; снимаем ИК-фильтр и ставим 850 нм подсветку.
* **128×128 — это мало.** Для прототипа нормально, но итоговый визор захочет
  дисплей 640×480 и выше (см. риски и путь апгрейда).

## Текущая архитектура (целевая)

```
OV7670 ──DVP 8 бит──► ESP32 ──SPI 27–40 МГц──► TFT 128×128 ──► линза ──► глаз
   │                    │
   └──SCCB (I2C)────────┘
                        └──► ИК-подсветка 850 нм (PWM + MOSFET)
```
