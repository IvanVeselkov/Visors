# 06. Схема подключения

## 0. На какую конфигурацию рассчитано

* **ESP32 DevKit, классический** (`ESP32-WROOM-32`, 3.3 В логика).
* **OV7670**, 18-пиновый модуль **без FIFO**.
* **TFT 1.44" 128×128**, 8 пинов, SPI.
* Питание: 1×18650 → 5 В → `VIN` ESP32.

> Если у тебя ESP32-S3 — см. раздел 8, пины камеры там другие.

### 1.1. Как читать надписи на плате

На большинстве плат ESP32 DevKit пины подписаны **`D` + номер**, и этот номер —
это и есть номер GPIO. То есть **`D23` = GPIO23**, `D4` = GPIO4, `D15` = GPIO15.

Это **не** Arduino-нумерация. У Arduino Nano `D2` — это «второй цифровой вывод»
(PD2), а у ESP32 `D2` — это физический GPIO2. Не путать, если рядом лежит Nano.

| Надпись на плате | GPIO | У нас используется как |
|---|---|---|
| `D0` / `IO0` | 0 | XCLK камеры |
| `D2` | 2 | TFT DC |
| `D4` | 4 | TFT RESET |
| `D5` | 5 | камера D0 |
| `D12` | 12 | затвор MOSFET ИК |
| `D13` | 13 | TFT MOSI |
| `D14` | 14 | TFT SCK |
| `D15` | 15 | TFT CS |
| `D16` / `RX2` | 16 | кнопка MODE |
| `D17` / `TX2` | 17 | кнопка ZOOM |
| `D18` | 18 | камера D1 |
| `D19` | 19 | камера D2 |
| `D21` | 21 | камера D3 |
| `D22` | 22 | камера PCLK |
| `D23` | 23 | камера HREF |
| `D25` | 25 | камера VSYNC |
| `D26` | 26 | камера SDA (SIOD) |
| `D27` | 27 | камера SCL (SIOC) |
| `D32` | 32 | подсветка TFT |
| `D33` | 33 | кнопка IR |
| `D34` | 34 | камера D6 |
| `D35` | 35 | камера D7 |
| `VP` | 36 | камера D4 |
| `VN` | 39 | камера D5 |

Другие частые обозначения на платах:

| Надпись | GPIO | Комментарий |
|---|---|---|
| `TX0` | 1 | UART0 TX, нужен для логов |
| `RX0` | 3 | UART0 RX |
| `VP` / `SENSOR_VP` | 36 | только вход |
| `VN` / `SENSOR_VN` | 39 | только вход |
| `EN` / `RST` | — | сброс, не GPIO |
| `CMD`, `CLK`, `SD0–SD3` | 11, 6, 7–10 | **flash, не использовать** |

> **Проверь GPIO0.** На 30-пиновых платах (DOIT DevKit V1) вывод GPIO0 часто
> не выведен на гребёнку — он есть только как кнопка `BOOT`. Если пина `D0`
> нет, XCLK камеры надо перенести (см. примечание в конце раздела 2).

## 2. Камера OV7670 (все 18 пинов)

| OV7670 | ESP32 | Примечание |
|---|---|---|
| 3V3 | 3V3 | питание модуля (на нём LDO 2.8 В) |
| GND | GND | |
| SCL | GPIO27 | SCCB |
| SDA | GPIO26 | SCCB |
| VSYNC | GPIO25 | |
| HREF | GPIO23 | |
| PCLK | GPIO22 | |
| XCLK | GPIO0 | 8 МГц от ESP32 |
| D7 | GPIO35 | |
| D6 | GPIO34 | |
| D5 | GPIO39 | |
| D4 | GPIO36 | |
| D3 | GPIO21 | |
| D2 | GPIO19 | |
| D1 | GPIO18 | |
| D0 | GPIO5 | |
| RESET | 3V3 | или через 10 кОм на 3.3 В |
| PWDN | GND | сенсор всегда включён |

**Важно:**

* Пины данных на классическом ESP32 **не выбираются** — это фиксированная
  распиновка I2S0 (как у ESP32-CAM). Перепутать нельзя.
* Провода данных — максимально короткие и одной длины, ≤ 10 см.
  Dupont-«сопли» 20 см дают сдвиг бит и полосы.
* Если на модуле нет подтяжек SCCB (обычно есть, 10 кОм на 2.8 В) —
  добавить 4.7 кОм с SDA и SCL на 3.3 В.
* XCLK — это выход ESP32. Если на нём 0 В, камера не выдаст ни кадра.

### Если на плате нет вывода GPIO0

На 30-пиновых DevKit V1 вывод `D0` часто отсутствует (GPIO0 — только кнопка
`BOOT`). Тогда XCLK переносится на свободный пин, потому что XCLK — это просто
LEDC-выход, а не часть фиксированной шины I2S.

Рабочая замена:

| Сигнал | Было | Стало |
|---|---|---|
| XCLK камеры | GPIO0 | **GPIO16** |
| Кнопка MODE | GPIO16 | **GPIO12** (с кнопкой на GND это безопасно) |
| Затвор MOSFET ИК | GPIO12 | **GPIO33** |
| Кнопка IR | GPIO33 | убрать, IR включать долгим нажатием ZOOM |

Данные камеры (D0–D7, PCLK, VSYNC, HREF) и SCCB при этом **не меняются** —
они жёстко привязаны к I2S0. В скетче правится только `CAM_PIN_XCLK`.

## 3. Дисплей (все 8 пинов)

| Дисплей | ESP32 | Примечание |
|---|---|---|
| GND | GND | |
| VCC | 3V3 | **не 5 В** |
| SCL | GPIO14 | SCK |
| SDA | GPIO13 | MOSI |
| RES | GPIO4 | сброс |
| DC | GPIO2 | команда/данные |
| CS | GPIO15 | + 10 кОм на 3.3 В |
| BLK | GPIO32 | подсветка, PWM |

Порядок пинов сверить с шелкографией: у части модулей `CS` и `BLK`
поменяны местами. **Перепутанное питание убивает модуль.**

## 4. Кнопки

Все три одинаково: `GPIO → кнопка → GND`, внутренняя подтяжка вверх.

| Кнопка | GPIO |
|---|---|
| MODE (день/ночь, меню) | 16 |
| ZOOM (1×/2×) | 17 |
| IR (подсветка вкл/выкл) | 33 |

## 5. ИК-подсветка

### Схема драйвера

```
        +5 В
          │
       ┌──┴──┐
       │ IR  │  850 нм, 1–3 Вт (или 4× 5 мм)
       └──┬──┘
          │  (катод)
   ┌──────┴──────┐
   │             │
  D             S
   │   MOSFET    │
   └──────┬──────┘
          │
         GND

GPIO12 ──[100 Ом]── G
                  G ──[10 кОм]── GND
```

* MOSFET — логического уровня: **AO3400** (SOT-23, до 4 А) или **IRLZ44N**
  (TO-220). Обычный IRF540 без логического уровня от 3.3 В не откроется.
* Резистор 10 кОм затвор–GND обязателен: GPIO12 — strapping-пин, при старте
  он должен быть низким, иначе ESP32 выберет не то напряжение flash.
* PWM от ESP32 — 20 кГц, чтобы не было мерцания в кадре.

### Ток и резистор

| Вариант | Расчёт | Итог |
|---|---|---|
| 4× 5 мм, 20 мА | (5 − 1.5) / 0.02 = 175 Ом на каждый | 180 Ом, 4 шт параллельно, ~80 мА |
| 1 Вт, 350 мА | (5 − 1.8) / 0.35 = 9.1 Ом | 10 Ом ≥ 2 Вт (КПД ~35 %) |
| 3 Вт, 700 мА | (5 − 1.8) / 0.7 = 4.6 Ом | 4.7 Ом ≥ 5 Вт (КПД ~45 %) |

Резистор — плохое решение для ваттных светодиодов: половина энергии уходит
в тепло. Правильно — **драйвер постоянного тока** (модуль CC или AMC7135
на 350 мА). Для первого включения сойдёт и резистор, но не гонять долго.

**Светодиод — только светодиод.** Никаких лазерных модулей: необратимое
повреждение сетчатки и запрет на играх.

## 6. Питание

```
 18650 (3.0–4.2 В)
      │
   TP4056  (заряд + защита)
      │
   MT3608  (boost 5 В, ≥ 2 А)
      │
      ├──► VIN ESP32 ──► AMS1117 ──► 3.3 В ──► камера, дисплей
      │
      └──► +5 В ──► [драйвер] ──► ИК-светодиоды

  Конденсаторы: 470 мкФ на 5 В у ESP32, 100 нФ у камеры, 10 мкФ у дисплея.
```

| Потребитель | Ток |
|---|---|
| ESP32 (Wi-Fi выкл.) | 100–150 мА |
| OV7670 | 60–100 мА |
| TFT 128×128 | 20–30 мА |
| ИК-подсветка | 80–700 мА |
| **Итого пик** | **~1.1 А** |

Boost должен держать 1.5 А с запасом, иначе при включении подсветки
ESP32 будет перезагружаться. 18650 на 3000 мА·ч: ~2.5–3 ч с подсветкой.

**Не питать ИК-подсветку от USB** — ток ограничен 500 мА, будет просадка.

## 7. Порядок сборки и проверки

1. **Плата отдельно.** USB → проверить 3.3 В на пине `3V3`.
2. **Дисплей.** Только 6 проводов. Прошить `firmware/display_test`, подобрать
   env (драйвер + смещение). Не идти дальше, пока картинка не станет чистой.
3. **Камера.** Подключить все 18. Прошить `firmware/live_view`.
   В логе должно быть `PID=0x76 VER=0x73`. Нет — проверить SCCB и XCLK.
4. **Кнопки.** Проверить `INPUT_PULLUP` тестом.
5. **ИК-драйвер.** Сначала на лабораторном БП с ограничением 300 мА,
   потом от аккумулятора.
6. **Всё вместе.** Проверить, что при включении подсветки не проседает
   питание и не перезагружается ESP32.

### Контрольные точки мультиметром

| Точка | Ожидание |
|---|---|
| 3V3 | 3.28–3.32 В |
| 5 В (VIN) | 4.9–5.1 В |
| XCLK (GPIO0) | ~1.6 В среднего (меандр 8 МГц) |
| VSYNC (GPIO25) | ~1.6 В среднего, меняется если камера шлёт кадры |
| Затвор MOSFET | 0 В при выкл., 3.3 В при 100 % |

Без осциллографа XCLK проверяется так: если на нём 0 В или 3.3 В —
генерации нет, камера мертва.

## 8. Если ESP32-S3

Пины камеры у S3 **не фиксированы** (LCD_CAM, а не I2S), поэтому можно
оставить ту же логику, но переназначить. Ограничения:

* GPIO 33–37 заняты на модулях с octal PSRAM (WROOM-1 N8R8 и подобные).
* GPIO 0, 3, 45, 46 — strapping.
* GPIO 19, 20 — USB.

Рекомендуемая карта для S3 (пример, проверять по своей плате):

| Сигнал | GPIO S3 |
|---|---|
| D0–D7 | 4, 5, 6, 7, 15, 16, 17, 18 |
| PCLK | 8 |
| VSYNC | 9 |
| HREF | 10 |
| XCLK | 11 |
| SIOD / SIOC | 12 / 13 |
| TFT SCK/MOSI/CS/DC/RST/BL | 14 / 21 / 47 / 48 / 2 / 42 |

## 9. Чего в этой схеме ещё нет

* Контроль заряда (нет свободного АЦП) — добавить ADS1115 по I2C позже.
* Разъём microSD для записи — добавить на свободные пины или по SPI.
* Датчик освещённости для авто-включения ИК.
* Экран/меню настроек — пока только кнопки и лог в Serial.
