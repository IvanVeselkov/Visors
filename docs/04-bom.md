Обязательное — без этого прототип не собрать. Желательное — заметно улучшает
результат. Цены ориентировочные, РФ, 2026, для заказа в одном месте.

## Расходники для пайки

Припой, флюс, спирт/изопропанол, зубочистки, медная оплётка — если ещё нет.

## Чего покупать **не** надо

* Второй Arduino Nano — для видео бесполезен.
* OV7670 «ещё один» — сначала выжать этот.
* ИК-лазер — опасен для глаз и запрещён на играх; нужны светодиоды.
* Готовый «night vision» модуль на AliExpress — это другой проект, свой
  интереснее и ремонтопригоднее.
